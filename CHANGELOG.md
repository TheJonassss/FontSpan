# Changelog

All notable changes to FontSpan.

## [1.1.0] - 2026-10-19

### Added
- "View all languages" screen, showing every language the font covers
  completely.
- Export Report: a PDF summary of a font's coverage. Six sections to
  choose from — General Summary, Unicode Blocks, Google Fonts
  Glyphsets, Complete Languages, Incomplete Languages, and Missing
  Glyphs (every glyph still missing, listed once with its name and
  Unicode value).

## [1.0.0] - 2026-09-29

### Added
- Initial release. Unicode block, Google Fonts glyphset, and language
  coverage analysis for .ttf, .otf, and .glyphs files, with
  cross-referenced recommendations for what to draw next. One-time
  purchase, 15-day trial.

  ## [1.1.1] - 2026-10-20

### Fixed
- Export Report modal no longer claims the PDF opens ready to edit in
  Figma. That's not true — only Illustrator supports that. The text
  now says the PDF is a starting point you can customize further in
  your design tool of choice.
- Font names and file names with quotes or special characters no
  longer break the layout.
- The language search box no longer breaks when the search text
  contains a quote.
